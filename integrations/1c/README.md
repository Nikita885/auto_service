# 1С: клиент по номеру

Внешняя обработка для «1С:Предприятия»: сотрудник входит своим телефоном и
паролем (как в панели мастера на сайте), вводит номер клиента в любой записи
— «8 900…», «+7 900…» или последние 4–9 цифр — и видит ту же карточку, что
на сайте:

- имя, телефон, с какого числа клиент;
- машины (основная отмечена);
- баллы: баланс и сколько можно списать в ближайшую запись;
- кто пригласил (номер замаскирован, как на сайте);
- ближайшие и последние прошлые записи: время, код, услуга, категория,
  точка, машина, сумма, баллы, комментарий, статус;
- последние звонки: итог, причина, кто звонил, заметка.

Нашлось несколько клиентов (например, по последним цифрам) — список, щелчок
по имени открывает карточку.

Данные берутся из API сайта с правами вошедшего сотрудника: мастер видит
записи и звонки только своих точек — ровно как в панели. Ничего в 1С не
записывается и в базу 1С не попадает.

## Что нужно

- «1С:Предприятие» 8.3.10 или новее, тонкий клиент. Обработку писали под
  платформу 8.3; на 8.5 она должна работать так же, но на живой платформе её
  ещё не проверяли.
- Доступ в интернет к сайту (`https://moi-servis.ru`). В клиент-серверной
  1С запросы идут **с сервера 1С** — доступ нужен ему.
- Учётная запись мастера или администратора на сайте — те же телефон и
  пароль, что для `/master/`. Клиентов обработка не пускает.

## Как собрать (один раз, 5 минут)

Обработка хранится в репозитории текстом: двоичный `.epf` в git не сравнить и
не проверить. Форма собирается кодом, поэтому в Конфигураторе нужна только
пустая форма и один модуль.

1. Откройте Конфигуратор любой базы. **Файл → Новый… → Внешняя обработка →
   ОК.**
2. Имя — `МойСервисКарточкаКлиента`, синоним — «Мой Сервис: клиент по
   номеру».
3. Вкладка **«Формы»** → «Добавить» → «Форма обработки» → «Готово». Форма
   станет основной.
4. В редакторе формы откройте вкладку **«Модуль»**, удалите всё и вставьте
   содержимое [`client_card_form.bsl`](client_card_form.bsl).
5. **Файл → Сохранить как…** → `МойСервисКарточкаКлиента.epf`.

Обновили `client_card_form.bsl` — повторите шаги 4–5 в том же `.epf`.

## Как пользоваться

1. В «1С:Предприятии» **Файл → Открыть…** → `МойСервисКарточкаКлиента.epf`.
   1С спросит, открывать ли внешнюю обработку, — подтвердите (нужно право
   на интерактивное открытие внешних обработок). Обработка откроется
   отдельной вкладкой.
2. Вкладка **«Вход»**: адрес сайта (по умолчанию `https://moi-servis.ru`),
   телефон и пароль сотрудника → «Войти».
3. Вкладка **«Клиент»**: номер → Enter или «Найти».

Адрес сайта и телефон для входа запоминаются в настройках пользователя 1С;
пароль — нет. После входа в форме остаются только токены сессии: закрыли
вкладку или нажали «Выйти» — сессии нет. Токен живёт час и обновляется сам;
не обновился (сотрудника заблокировали, прошло 30 дней) — обработка вернёт
на «Вход».

Через «Дополнительные отчёты и обработки» (БСП) подключать можно, но там
обработки по умолчанию работают в безопасном режиме, а он запрещает
HTTP-запросы: в карточке обработки нужно разрешить ей работу без
безопасного режима (делает администратор 1С). Проще открывать через
«Файл → Открыть…».

## Если не работает

| Сообщение | Что делать |
|---|---|
| «Нет связи с сайтом: …» | Проверьте адрес и доступ в интернет с компьютера (или сервера) 1С; прокси обработка не использует |
| «Неверный телефон или пароль» | Те же телефон и пароль, что для панели мастера; у клиентов пароля нет |
| «Слишком много запросов» | Несколько неудачных входов подряд — подождите и попробуйте снова |
| «Сессия истекла — войдите снова» | Войдите заново: токен не обновился |
| Карточка пустая, записей нет | Мастер видит только свои точки — как на сайте |

Проверить на своём компьютере: адрес `http://localhost:8000` и демо-учётка
мастера из основного README.

## Как устроено

- `ПриСозданииНаСервере` добавляет реквизиты (`ИзменитьРеквизиты`),
  вкладки, поля и команды. Поэтому реквизиты в коде — `ЭтотОбъект["Имя"]`:
  при компиляции модуля их ещё нет.
- HTTP — `HTTPСоединение` на сервере (`&НаСервереБезКонтекста`), так
  обработка работает и в веб-клиенте. Адреса:
  `POST /api/v1/auth/staff/login/`, `POST /api/v1/auth/token/refresh/`,
  `GET /api/v1/master/clients/?phone=`, `GET /api/v1/master/clients/{id}/` —
  те же, что у панели мастера (см. «Клиент по номеру и карточка» в основном
  README). Сайт для обработки не менялся.
- Карточка — HTML в поле HTML-документа. Всё, что пришло с сайта, проходит
  экранирование: имя или комментарий с «<» не станут разметкой.
